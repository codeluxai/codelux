# Codelux

### A new helper for your AI

Your whole project, kept like a living book your AI can read from — low-token
algorithms, persistent memory, a live knowledge graph and instant search.
Notes, CodeMap, Brief, one guarded write path and a journal. Index and memory
stay on your machine; AI calls go only to the provider you choose.

## What's in this repo

Signed release binaries only — the Free build of Codelux, published straight
from [codelux.ai](https://codelux.ai). No source code here: see
[codelux.ai/legal](https://codelux.ai/legal) for licensing terms.

Every release lists its SHA-256 checksum in the asset notes — verify before running:

```
sha256sum codelux_<version>_<arch><ext>
```
